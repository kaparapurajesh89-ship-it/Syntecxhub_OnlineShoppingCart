# Syntecxhub_OnlineShoppingCart
🛒 Online Shopping Cart System

The Online Shopping Cart System is a Java-based application developed using core concepts like ArrayList and HashMap to simulate a simple e-commerce experience. The system allows users to browse available products, add items to their cart, view selected items, and calculate the total cost efficiently.

An ArrayList is used to store and manage the list of available products, including details such as product ID, name, and price. A HashMap is used to manage the shopping cart, where each product ID is mapped to its corresponding quantity, enabling quick updates and retrieval.

The application provides a menu-driven interface that ensures a smooth and user-friendly experience. Users can perform operations like adding items, viewing cart contents, and checking the total bill with clear prompts and simple navigation.

This project demonstrates the effective use of Java collections for real-time data handling and highlights fundamental programming concepts such as object-oriented design, data structures, and user interaction.
